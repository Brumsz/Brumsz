## 👨‍💻 Sobre mim

Estudante de **Ciência da Computação** (6º semestre, UNIP), com foco em **Backend** e um interesse forte em **IA aplicada e automação**. Construo experiência prática desenvolvendo projetos reais para clientes enquanto me preparo para minha primeira posição formal no mercado de tecnologia.

- 🔭 Trabalhando atualmente como **Desenvolvedor de Automação e IA (Freelancer)**, entregando chatbots de WhatsApp, sistemas RAG e automações de negócio.
- 🧠 Já entreguei um chatbot com **IA generativa (Claude API)** via **FastAPI + Evolution API**, e sistemas de **RAG com PostgreSQL + pgvector** para busca semântica.
- ⚙️ Construí integrações com **n8n**, **Google Calendar**, **Gmail** e **Notion** para automatizar operações de back-office e qualificação de leads.
- 🔐 Implementei autenticação **JWT/OAuth2** do zero, entendendo cada etapa do fluxo de segurança.
- 🧪 Escrevo testes automatizados com **pytest** para garantir cobertura e confiabilidade.
- 📚 Fundamentos sólidos em estruturas de dados, algoritmos, banco de dados e arquitetura de sistemas — reforçados por cursos complementares (Alura, SENAI).
